# 个人提交成果页面设计

## 目标

新增个人端成果提交页面，替换固定的“交付成果 + 附件”填写方式。页面根据任务发布时绑定的成果模板快照生成提交字段。

## 页面与数据

- PC 页面：`result-submit.html`
- 小程序页面：`result-submit-mini.html`
- 页面使用一个内置示例任务，任务包含基础信息、结算数量配置和成果模板字段快照。
- 个人提交者不能选择或切换模板。
- 页面只读取任务快照；后续修改模板不会影响已接单任务的提交项。

## 页面结构

1. 任务信息：任务名称、任务编号、客户名称、结算方式和单价。
2. 固定数量：始终展示，不属于成果模板字段。任务通过 `quantityLabel` 和 `quantityUnit` 决定展示名称和单位，例如“工时数（时）”或“天数（天）”。
3. 交付成果：按任务的 `templateSnapshot.fields` 顺序生成字段。
4. 底部操作：取消和确认提交。

## 终端呈现

- PC 页面采用任务信息卡片、成果表单和固定底部操作栏，适合桌面端填写与文件上传。
- 小程序页面使用单列移动布局、紧凑任务摘要和底部安全区提交按钮，字段规则与 PC 页面完全一致。
- 两个页面都使用相同的示例任务快照，不提供模板选择器。

## 字段渲染

| 字段类型 | 个人端控件 |
| --- | --- |
| 单行文本 | 单行输入框 |
| 多行文本 | 多行输入框及字数统计 |
| 日期时间 | 日期时间输入框 |
| 单选 | 单选按钮组 |
| 多选 | 多选框组 |
| 图片上传 | 图片文件选择，展示文件名并支持移除 |
| 文件上传 | 文件选择，展示文件名并支持移除 |
| 视频上传 | 视频文件选择，展示文件名并支持移除 |

单选、多选的候选项从模板字段的 `options` 中按 `#` 拆分。

## 提交规则

- 固定数量必填，必须大于 0。
- 标记为必填的模板字段必须填写或上传文件。
- 点击确认后，原型展示“提交成功，等待审核”提示，不调用后端接口。
- 取消按钮关闭当前页面或返回上一页。

## 验收点

- 页面没有模板选择器。
- 固定数量能以“工时数 / 天数”等任务级名称展示。
- 必填字段显示红色星号并在提交时校验。
- 所有当前成果模板字段类型都能生成对应的提交控件。
- 单选、多选使用 `#` 分隔的选项配置。
