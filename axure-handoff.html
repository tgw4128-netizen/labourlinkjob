成果模板配置模块原型说明

用于给开发说明页面范围、交互规则、数据结构和验收口径。
打开成果模板配置页 打开模板应用页 打开 PC 提交页 打开小程序提交页 打开版本记录页

原型总览

本交付页相当于 Axure 的“页面说明 + 交互备注”视图。

交付给开发
进入配置 运营人员进入成果模板配置，维护岗位成果提交模板。
新增模板 配置模板名称、适用岗位分类、模板状态和个人端提示语。
配置字段 字段名称、字段类型、是否必填、填写说明支持自定义；单选/多选时填写选项备注。
启用模板 启用后岗位可复用该模板，保存启用产生版本记录。
引用模板 岗位发布时选择模板，带出字段配置，并允许当前岗位调整。
查看历史 版本记录只展示模板历次变动，并可查看当时字段。
页面 用途 开发入口 备注
成果模板配置 模板列表、筛选、新增、编辑、预览、版本记录入口。 template-config.html 模板可以同时适用于多个岗位分类。
模板应用 岗位发布时选择成果模板，自动带出提交字段。 template-apply.html 当前岗位可在模板字段基础上单独调整。
PC 提交成果 个人按任务快照填写固定数量与交付成果。 result-submit.html 不提供模板选择器。
小程序提交成果 移动端单列填写页面，字段规则与 PC 端一致。 result-submit-mini.html 底部提交栏兼容安全区。
版本记录 查看模板历次启用、字段调整、分类调整记录。 template-version-record.html 不展示操作类型，保留变更内容和查看字段。

交互备注
  1. 选择成果模板后，系统复制模板字段快照到当前岗位配置中。
  2. 当前岗位可修改字段名称、字段类型、是否必填、填写说明；字段类型为单选/多选时可填写选项备注。
  3. 字段表格中必填字段展示红色星号，个人端提交页按最终字段快照生成。
  4. 保存岗位时应保存“引用模板 ID、版本号、岗位字段快照”，避免模板后续变更影响已发布岗位。

交互备注
  1. 个人端不选择模板，任务保存模板字段快照。
  2. 工时数、天数等数量字段属于任务结算配置，不属于模板字段。
  3. 必填数量与必填模板字段均显示红色星号，提交时必须校验。

  5. 上传字段支持选择文件、展示文件名和移除文件；原型不接入后端上传。

交互备注

  1. 点击“新增模板”打开新增/编辑模板弹窗。
  2. 点击“预览”查看个人端提交效果，只读展示。

新增/编辑模板

字段直接自定义配置，适用岗位分类支持全部或一级-二级级联多选。

弹窗
1 适用岗位分类 先选择“全部”或“指定分类”。选择“全部”时不需要再选择具体分类；选择“指定分类”时，使用级联多选组件，左侧一级分类支持多选，选中一级时默认选中该一级下全部二级。
2 字段配置必填标记 字段名称、字段类型、必填三列标题前展示红色星号。个人端提交时，必填字段也需要红色星号提示。
3 字段配置范围 只保留字段名称、字段类型、是否必填、填写说明、备注；不需要审核说明和校验规则。
配置项 类型 是否必填 开发备注
* 模板名称 输入框 是 建议限制 50 字以内，保存时校验不可为空。
* 适用岗位分类 一级-二级级联多选 是 “全部”建议存范围标识；指定分类时存二级分类 ID，同时冗余展示名称。
* 模板状态 下拉选择 是 草稿、已启用、已停用。启用后前端可被岗位引用。
个人端提示语 多行文本 否 展示在个人提交成果页面顶部。
* 字段名称 输入框 是 同一模板内字段名称建议不重复。
* 字段类型 下拉选择 是 单行文本、多行文本、图片上传、文件上传、视频上传、日期时间、单选、多选。
* 必填 下拉选择 是 控制个人端提交时是否必须填写。
填写说明 输入框 否 作为个人端字段下方或占位提示展示。
备注 输入框 单选/多选时必填 字段类型为单选或多选时展示输入框，填写选项，多个选项用 # 分隔；其他类型显示“非单选/多选无需配置”。

  1. “操作类型”列不展示。
  2. “变更内容”列保留，用一句话描述本次变动。
  3. “查看”按钮保留，点击后弹窗查看该版本字段。
  4. 版本记录按生效时间倒序排列。

查看字段

从版本记录点击“查看”后弹出，只读展示当时版本字段。

弹窗
排序 字段名称 字段类型 必填 填写说明
1 服务前照片 图片上传 是 上传任务开始前照片
2 服务后照片 图片上传 是 上传任务完成后照片
3 完成说明 多行文本 是 描述任务完成情况

开发备注

  • 字段查看弹窗只读，不允许编辑历史版本字段。
  • 字段数据应读取版本快照，不能读取模板当前字段，否则历史版本会失真。
  • 关闭弹窗后回到版本记录列表，保留当前选中的模板。

开发说明

给开发评审使用的数据结构、接口和验收标准。

交付备注
模块 建议接口 说明
模板列表 GET /api/templates 支持模板名称、岗位分类、状态分页查询。
保存模板 POST /api/templates 保存基础信息、适用岗位分类、字段配置。启用时生成版本快照。
版本记录 GET /api/templates/{id}/versions 返回版本号、状态、变更内容、操作人、生效时间。
查看字段 GET /api/templates/{id}/versions/{version}/fields 返回该版本对应的字段快照。
验收项 验收标准
岗位分类多选 一级和二级均支持多选；选中一级默认选中全部二级；父级半选状态正确。
字段自定义 可新增、删除字段；字段名称、字段类型、必填项红星标记完整；单选/多选支持选项备注。
版本记录 不展示操作类型；展示变更内容；查看按钮可打开字段快照。
模板复用 一个模板可以同时适用于多个岗位分类，岗位发布时可按分类匹配模板。

全局开发备注

以下备注对应本次成果模板配置模块的开发口径。

1. 模板和岗位分类关系 模板与岗位分类是多对多关系，前端展示为“一级-二级”。
2. 字段配置 字段由运营自定义，当前范围只包含名称、类型、必填、填写说明。
3. 必填提示 后台字段配置表头和个人端提交字段都需要红色星号。
4. 版本快照 每次启用或关键变更生成版本记录，历史字段以快照为准。
5. 版本记录范围 页面只记录历次模板变动，不展示审核说明、校验规则、操作类型。
